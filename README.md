# Anime Photo Transformer

Crie artes incríveis de seus personagens favoritos de anime usando Inteligência Artificial.

## 🚀 Tecnologias

- **Next.js 15+**
- **Tailwind CSS**
- **Framer Motion** (Animações Premium)
- **Pollinations.ai API** (Geração de Imagens)

## 🎨 Créditos e Requisitos

Este projeto foi construído utilizando os serviços da **Pollinations.ai**.

- **API:** [Pollinations.ai](https://pollinations.ai)
- **Modelo:** FLUX
- **Badge:** Built with Pollinations.ai

---

### Como rodar localmente

1. Clone o repositório
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Rode o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse `http://localhost:5000`
